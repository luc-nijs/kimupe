# kimupe.education

Website of KiMuPe, rebuilt in [Astro](https://astro.build) from the Wix site.

```bash
npm install
npm run dev
```

- `src/pages/` – one file per page, mostly with the same addresses as on Wix
- `src/layouts/Base.astro` – header, menu and footer
- `src/data/nav.js` – the menu
- `src/styles/site.css` – layout, fonts and colours
- `public/` – images and the ISME 2026 PDFs
